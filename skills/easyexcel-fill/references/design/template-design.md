# 模板设计规范与真实业务模板

> 来源：https://easyexcel.opensource.alibaba.com/docs/current/quickstart/fill

## 1. 设计原则

1. **样式在模板里设计**：填充只替换变量，不改样式
2. **list 必须放最后一行**：避免复杂填充（forceNewRow）导致 OOM
3. **合计行用 write 追加**：list 之后的内容用 `write`，不要用 `fill`
4. **变量名与 Java 字段严格匹配**：Map 的 key / DTO 的 field name
5. **特殊字符用 `\{` `\}`**：模板中出现 `{` `}` 必须转义
6. **公式预置在模板里**：填充时不会重算

## 2. 6 种典型业务模板

### 2.1 简单对象模板（合同/单据）

```
┌─────────────────────────────┐
│  公司：{company}            │
│  员工：{name}               │
│  日期：{date}               │
│  金额：{amount}             │
└─────────────────────────────┘
```

填充代码：
```java
EasyExcel.write(fileName).withTemplate(template).sheet().doFill(data);
```

### 2.2 列表模板（订单/明细）

```
┌────┬──────────┬──────┐
│ ID │ 名称     │ 金额 │
├────┼──────────┼──────┤
│{.id} │{.name} │{.amount} │
│    │         │      │  ← 列表展开
└────┴──────────┴──────┘
```

**官方原文**："模板中 `{.}` 表示 list"
**注意**：模板中**只画一行** `{.}` 即可，EasyExcel 会自动展开多行。

### 2.3 复杂列表 + 合计行（对账单）

```
┌────┬──────────┬──────┐
│ ID │ 名称     │ 金额 │
├────┼──────────┼──────┤
│{.id} │{.name} │{.amount} │
│    │         │      │  ← list 展开
├────┴──────────┴──────┤
│           合计:       │  ← 模板里预置
└───────────────────────┘
```

**两种方案**：
- **方案 A（推荐，大数据量）**：模板里**删除**合计行，list 放最后一行，代码用 `write` 追加合计行
- **方案 B（简单场景）**：模板里保留合计行，代码用 `forceNewRow=true`

### 2.4 横向多列模板（财务报表）

```
┌────────┬──────┬──────┬──────┐
│ 项目   │ 1月  │ 2月  │ 3月  │
├────────┼──────┼──────┼──────┤
│ 收入   │{.1}  │{.2}  │{.3}  │  ← 横向展开
└────────┴──────┴──────┴──────┘
```

需要 `FillConfig.direction(HORIZONTAL)` + `FillWrapper`（如不需要多 list，可省略 wrapper）。

### 2.5 多列表组合模板

```
┌─────────────────────┐
│ 销售:{salesData.id} │
│ 库存:{stockData.id} │
└─────────────────────┘
```

需要 `new FillWrapper("salesData", salesList)` + `new FillWrapper("stockData", stockList)`。

### 2.6 含公式的模板（发票/报表）

```
┌──────┬──────┬──────┐
│ 单价 │ 数量 │ 小计 │
├──────┼──────┼──────┤
│{.price} │{.qty} │=A2*B2 │
└──────┴──────┴──────┘
```

**官方原文**："函数（=A2&B2） 这里是不会被填充的"
**注意**：公式在 Excel 中预置，EasyExcel 不会改写公式（只保留）。

## 3. 转义字符完整规则

| 模板原义 | 模板写法 | 说明 |
|---------|---------|------|
| 字面 `{` | `\{` | 避免被识别为变量开始 |
| 字面 `}` | `\}` | 避免被识别为变量结束 |
| 变量 `{name}` | `{name}` | 正常占位符 |
| 列表 `{.}` | `{.}` | 列表占位符 |
| 列表 `{data1.}` | `{data1.}` | 带前缀列表 |

**示例**：模板中要显示"状态: {启用}"，应写为"状态: \{启用\}"。

## 4. 模板设计 Checklist

- [ ] 变量名与 Java 字段完全一致（区分大小写）
- [ ] list 占位行只画一行（`{.}` 自身不重复）
- [ ] 大数据量时 list 是最后一行
- [ ] 特殊字符已用 `\{` `\}` 转义
- [ ] 多 list 用了不同前缀
- [ ] 横向多列用了 `FillWrapper` + `HORIZONTAL`
- [ ] 合计行用 `write` 追加（不要在模板里预置）
- [ ] 公式直接预置在模板里
- [ ] 模板是 `.xlsx`（07 版），不是 `.xls`（03 版）

## 5. 模板验证方法

```java
// 1. 填充前先 dry-run：用最小数据测一遍
FillData test = new FillData();
test.setName("测试");
EasyExcel.write("/tmp/test.xlsx").withTemplate(templatePath)
    .sheet().doFill(test);

// 2. 打开文件，确认：
//    - 所有 {} 被替换
//    - 列表行被展开
//    - 样式保留
//    - 公式保留
```

## 6. 真实业务模板（来自社区实践）

### 工资条模板
```
┌────────────────────────────────────┐
│ 工资条                              │
│ 员工：{name}    工号：{id}          │
│ 基本工资：{baseSalary}             │
│ 绩效奖金：{bonus}                  │
│ 扣款：{deduction}                  │
│ 实发：{total}                      │
│ 发放日期：{payDate}                │
└────────────────────────────────────┘
```

### 销售合同模板
```
┌────────────────────────────────────┐
│ 销售合同                            │
│ 合同编号：{contractNo}             │
│ 甲方：{partyA}    乙方：{partyB}   │
│ 日期：{signDate}                  │
├────────────────────────────────────┤
│ 商品清单：                          │
│ ID │ 名称   │ 数量 │ 单价 │ 金额  │
│{.id} │{.name} │{.qty} │{.price} │{.amount}│
│                                    │
│ 总计：{totalAmount}                │
└────────────────────────────────────┘
```

### 月度对账单模板
```
┌────────────────────────────────────┐
│ 对账单                              │
│ 客户：{customer}                   │
│ 月份：{month}                      │
├────────────────────────────────────┤
│ 日期 │ 摘要 │ 收入 │ 支出 │ 余额  │
│{.date} │{.summary} │{.income} │{.expense} │{.balance}│
│                                    │
│ 【合计行由 write 追加】            │
└────────────────────────────────────┘
```
