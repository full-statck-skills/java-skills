# 03 版 vs 07 版

| 特性 | 03 版 (.xls) | 07 版 (.xlsx) |
|------|--------------|---------------|
| 简单对象填充 | ✅ 支持 | ✅ 支持 |
| 列表填充 | ✅ 支持 | ✅ 支持 |
| 复杂填充 (forceNewRow) | ❌ 不支持 | ✅ 支持 |
| 大数据量复杂填充 | ❌ 不支持 | ✅ 支持 |
| 多列表组合 | ❌ 不支持 | ✅ 支持 |
| 横向填充 | ❌ 不支持 | ✅ 支持 |

> **官方原文**："03版本 不支持大量数据的复杂填充"

```java
// 强制使用 07 版（默认）
EasyExcel.write(fileName).withTemplate(templateFileName).sheet().doFill(data);

// 03 版（仅简单场景）
// 不需要额外配置，EasyExcel 会根据文件名后缀自动判断
```
